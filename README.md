# LiveCoding Strasbourg / TOPLAP Strasbourg

Website of TOPLAP Strasbourg — live coding & digital arts in Strasbourg.
Built with [Astro](https://astro.build), published on GitHub Pages at
https://livecodingstrasbourg.github.io on every push to `main`.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # production build in ./dist
```

**To change content (events, artists, tools, images, links, pages), see
[EDITING.md](EDITING.md).**
